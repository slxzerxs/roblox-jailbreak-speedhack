Vehicle speed modification script for Roblox Jailbreak.

## Description
This script modifies vehicle speed in Jailbreak by applying directional force based on W/S input. It includes automatic multipliers for different vehicle types and works only for the driver.

### Features
- **Smooth Acceleration**: Uses `Heartbeat` for fluid force application
- **Vehicle-Specific Multipliers**:
- Bikes: 0.3x
-  - Buggies: 0.5x
- **Driver Only**: Only the driver can control the boosted vehicle
- **Directional Control**: Forward (W) and reverse (S) force application
